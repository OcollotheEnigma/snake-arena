# AI Usage Report

## Overview

AI assistance was used throughout the development of Snake Arena to accelerate planning, implementation, testing, debugging, and documentation.

## Where AI Was Used

AI helped with:

- Product specification and user stories
- Frontend HTML, CSS, and JavaScript
- Snake game logic and keyboard controls
- FastAPI backend structure
- SQLite persistence
- OpenAPI documentation
- Backend testing
- README and project documentation
- Debugging GitHub and development environment issues

## Human Verification

The generated code was reviewed and tested by the developer.

The developer verified that:

- The frontend loads correctly.
- The Snake game can be played.
- Keyboard controls work.
- The score changes when food is collected.
- Game-over behavior works.
- Scores can be submitted to the backend.
- Scores are stored in SQLite.
- The leaderboard retrieves saved scores.
- The backend API is available through FastAPI.

## Lessons Learned

AI assistance can speed up software development, but generated code still needs to be reviewed, tested, and corrected by the developer. The project therefore combined AI assistance with manual verification and testing.
